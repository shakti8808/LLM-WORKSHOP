## Why

Users need a lightweight, local task manager to track their daily activities. This project provides a fast, simple Python Flask-based Todo web application with a clean, modern interface and local JSON storage.

## What Changes

- Create a Python Flask Todo web application.
- Implement adding, completing, and deleting tasks.
- Implement persistent local storage of tasks in a JSON file (`tasks.json`).
- Develop a clean, modern web user interface using templates and static files.

## Capabilities

### New Capabilities

- `todo-management`: Capability to add, complete, delete tasks, and persist them locally in a JSON file, exposed via a web interface.
